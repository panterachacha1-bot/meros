# MEROS — энциклопедия великих людей Узбекистана

Статический сайт без сборки на трёх языках (узбекский, русский, английский): 41 личность, из них 9 джадидов.

## Что есть на сайте

- **Портреты** в едином стиле гравюры, созданные в Google Flow (Nano Banana) по архивным фото. Оригиналы лежат в `img/arxiv/` и открываются кнопкой «Архивный источник».
- **Линия жизни**: анимированная шкала событий и блоки «с чего начинал» и «к чему пришёл».
- **Три лучших произведения** у каждого, со своей страницей `asar.html?id=…&n=0..2`: аннотация на трёх языках, полный текст (22 произведения в общественном достоянии), аудио (20 произведений), ссылка на библиотеку.
- **Читалка**: постраничный текст, размер шрифта, запоминание страницы, прогресс чтения, чтение вслух голосом браузера.
- Каталог с фильтром «Джадиды», эпохи, тест, поиск по клавише `/`.

## Файлы

| Файл | Назначение |
|---|---|
| `js/data.js` | Биографии на узбекском |
| `js/people-ru.js`, `js/people-en.js` | Переводы биографий |
| `js/works.js` | Три лучших произведения и «линия жизни» на трёх языках |
| `js/audio.js` | Плейлисты (записи играют с сервера ziyouz.uz) |
| `js/i18n.js` | Переводы интерфейса |
| `js/app.js` | Логика всех страниц |
| `texts/` | Полные тексты произведений (латиница) |
| `publish.sh` | Публикация на GitHub Pages одной командой |

## Публикация в интернете

```bash
bash publish.sh
```

Скрипт поставит GitHub CLI, попросит войти в GitHub через браузер, создаст репозиторий `meros` и включит GitHub Pages. Адрес сайта будет `https://ВАШ_ЛОГИН.github.io/meros/`.

## Авторские права

Полные тексты даны только для авторов, умерших до 1955 года. Для остальных — краткое содержание и ссылка на библиотеку ziyouz.uz. Аудиозаписи не копируются, а воспроизводятся с ziyouz.uz.
